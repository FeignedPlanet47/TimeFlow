# TimeFlow

MVP приложения для отслеживания времени на Kotlin.

## Архитектура

- MVVM
- Clean Architecture: `data / domain / presentation`
- Jetpack Compose
- Room
- Hilt
- Coroutines + Flow
- Navigation Compose

## Реализовано

- категории занятий с начальными значениями;
- запуск таймера одной кнопкой;
- автоматическое завершение предыдущего таймера при старте нового;
- восстановление активной записи после перезапуска приложения за счёт хранения `startTimeMillis` в Room;
- остановка таймера;
- история за текущий день;
- аналитика по категориям за текущую неделю;
- тёмная тема по системной настройке.

## Что добавить следующим этапом

- экран создания/редактирования категорий;
- ручное добавление временного интервала;
- цели и лимиты;
- экран календаря;
- сравнение недель;
- streak;
- foreground service + постоянное уведомление активного таймера;
- Glance App Widget;
- экспорт CSV/JSON;
- резервное копирование / синхронизация.

## Запуск

Открыть папку проекта в актуальном Android Studio и выполнить Gradle Sync.
Текущая конфигурация использует compileSdk 37 и Java 17.
